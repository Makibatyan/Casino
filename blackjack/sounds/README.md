# 効果音ファイル

このフォルダの MP3 だけでゲームの効果音が動作します。  
**ユーザーのダウンロードフォルダなど、PC 上の別パスは一切参照しません。**

## ファイル一覧

| ファイル | 用途 |
|---------|------|
| `coin-low.mp3` | 少量ベット・コイン音 |
| `coin-high.mp3` | 多額ベット・コイン音 |
| `card-flip.mp3` | ヒット・ダブル（カードめくり） |
| `voice-blackjack.mp3` | 「Blackjack」ボイス |
| `voice-bust.mp3` | 「Bust」ボイス |
| `voice-win.mp3` | 「Win」ボイス（勝利演出） |
| `voice-lose.mp3` | 「Lose」ボイス（敗北演出） |
| `voice-even.mp3` | 「Even」ボイス（引き分け演出） |

## GitHub に公開する場合

- `sounds/` フォルダごとリポジトリに含めてください（`.gitignore` で除外しないこと）
- 素材のライセンス・出典は `ATTRIBUTION.md` を確認してください
- ボイスを差し替える場合は、同じファイル名で上書きするだけで OK です
